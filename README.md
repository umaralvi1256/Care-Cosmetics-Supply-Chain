# Care-Cosmetics-Supply-Chain
# Operations Optimization: Care Cosmetics

## Project Overview
This project analyzed the supply chain and distribution network of Care Cosmetics to understand why logistics costs were high and to improve delivery reliability. 

## Key Actions
* **Network Audit:** Evaluated current shipping processes to identify cost bottlenecks and potential service delays.
* **Proposed Strategy:** Recommended moving to regional distribution centers to get products closer to customers, reducing delivery times significantly.
* **Efficiency Gains:** Suggested using simple routing tools to help the fleet cut down on fuel waste and improve daily delivery performance.

## Business Value
The project provided a clear plan to reduce transportation overhead by 5-15% while improving overall customer satisfaction through faster delivery times.

## Tools Used
* **Excel:** Used for cost modeling and analyzing delivery data.
* **Operations Research:** Applied practical frameworks to improve supply chain workflows.
